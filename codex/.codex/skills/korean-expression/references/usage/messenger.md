# 메신저

Slack, Discord 같은 팀 메신저에 보내는 메시지에 적용한다. 기본 어미는 해요체다.

## 공통 규칙

- 첫 줄은 다음 표의 표지로 시작하고, 표지 뒤에 메시지의 요지를 한 문장으로 쓴다.
- 메시지는 코드 블록을 빼고 10줄 이하로 쓴다. 더 길면 Issue나 문서에 쓰고 링크한다.
- 같은 주제의 후속 메시지는 스레드 답글로 쓴다.
- Issue, PR과 문서는 제목과 링크를 함께 쓴다.
- 질문이 둘 이상이면 번호를 붙여 나열한다.
- 메신저에서 정한 결정은 Issue나 문서에 기록하고 스레드에 링크를 남긴다.
- 이모지를 본문에 쓰지 않는다. 반응은 메신저의 반응 기능으로 남긴다.

| 표지 | 쓰는 때 |
| --- | --- |
| `[공유]` | 정보나 결과를 알릴 때 |
| `[요청]` | 상대의 행동이 필요할 때 |
| `[질문]` | 상대의 답이 필요할 때 |
| `[공지]` | 팀 전체가 지켜야 하는 일정이나 규칙을 알릴 때 |

## 요청 메시지

- 요청 문장은 `<멘션> <할 일>을 <기한>까지 해 주세요.`로 쓴다.
- 기한은 날짜나 시각으로 쓴다. `빠르게`, `여유 될 때`로 쓰지 않는다.
- 요청 대상이 둘 이상이면 사람마다 요청 문장을 따로 쓴다.

## 작성 예시

다음은 가상 예시입니다.

```text
[요청] 정원 초과 응답 코드를 정해야 해요.
@서버담당 정원이 찬 여행의 참여 요청에 줄 응답 코드를 11월 25일까지 정해 주세요.
선택지는 409 TRIP_FULL과 200 참여 불가 상태 두 가지예요.
Issue: 정원 초과 응답 코드 결정 (#34) https://github.com/...
```
