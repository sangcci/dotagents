# 화면 설명

Figma에서 화면마다 남기는 화면 설명과, 다른 문서에서 화면을 가리키는 표기에 적용한다. 기본 어미는 한다체다.

## 원칙

- 화면 정의서를 저장소의 Markdown 문서로 쓰지 않는다. 화면 구성과 사용자 흐름은 Figma에 두고, 저장소 문서는 화면 식별자로 화면을 가리킨다.
- 화면 설명에는 사용자의 동작과 화면의 결과만 쓴다. 업무 규칙과 기준값은 정책서에, 요청과 응답은 API 스펙에 쓰고 `관련 문서`에 링크한다.
- 문구만 보여 주고 사용자가 다루지 않는 요소는 쓰지 않는다. Figma 화면이 이 요소를 보여 준다.
- 버튼 이름, 안내 문구와 오류 문구 같은 화면 문구는 이 가이드로 고치지 않는다. 화면 설명에 옮길 때는 원문을 유지한다.

## 화면 식별자

- 저장소에 화면 식별자 규칙이 있으면 따른다.
- 규칙이 없으면 `<도메인>-<번호>` 형식으로 쓴다. 도메인은 영문 대문자로, 번호는 두 자리로 쓴다. `TRIP-02`처럼 쓴다.
- 화면 하나에 식별자 하나를 붙인다. 화면을 지워도 식별자를 다른 화면에 다시 쓰지 않는다.
- 같은 화면의 상태별 프레임은 `<식별자> <상태 이름>`으로 이름을 붙인다. `TRIP-01 참여 불가`처럼 쓴다.

## 화면 설명 형식

Figma에서 화면 프레임마다 다음 형식의 설명을 하나 둔다.

```text
화면: `TRIP-01` 초대 코드 입력
목적: 회원이 초대 코드로 참여할 여행을 찾는다.

진입:
- 여행 목록의 `초대 코드 입력` 버튼
- 가입 직후의 첫 여행 목록

요소:
1. 코드 입력 칸에 코드를 입력함
   -> 앱이 `검색` 버튼을 켬
2. `검색` 버튼을 누름
   -> 앱이 여행명, 기간과 참여 인원을 보여 줌
3. `이 여행 참여하기` 버튼을 누름
   -> 앱이 여행 상세 화면(`TRIP-04`)으로 이동함

상태:
1. 유효한 코드를 검색함
   -> `TRIP-01 검색 결과`
2. 빈자리가 없는 여행의 코드를 검색함
   -> `TRIP-01 참여 불가`
3. 관리자가 확정한 여행의 코드를 검색함
   -> `TRIP-01 참여 불가`
4. 없는 코드를 검색함
   -> `TRIP-01 코드 오류`

관련 문서:
- 정책서: 초대 코드 검색과 참여
- API 스펙: 초대 코드 검색
```

- 항목은 `화면`, `목적`, `진입`, `요소`, `상태`, `관련 문서` 순서로 쓰고 빼지 않는다. 내용이 없는 항목에는 `없음`을 쓴다.
- `화면`에는 식별자와 화면 이름을 쓴다. 화면 이름은 명사구로 쓴다.
- `목적`은 `<사용자>가 <할 일>을 한다.` 한다체 문장 하나로 쓴다.
- `진입`에는 이 화면으로 들어오는 화면과 요소를 명사구로 쓴다.
- `요소`와 `상태`는 [적용 예시](../example-blocks.md#적용-예시)의 `조건과 행동 -> 결과` 형식으로 쓴다. 조건과 행동, 결과는 `-ㅁ`, `-음` 명사형으로 쓴다.
- `요소`의 결과에는 앱의 동작이나 이동할 화면을 쓴다. 다른 화면으로 이동하면 화면 이름 뒤 괄호에 식별자를 쓴다.
- `상태`의 결과에는 상태별 프레임 이름만 쓴다. 조건에는 기준값을 쓰지 않는다. `정원 6명이 참`이 아니라 `빈자리가 없음`으로 쓰고, 기준값은 정책서에서 확인한다.
- 다음 상태가 화면에 생기면 모두 `상태`에 쓰고 프레임을 하나씩 둔다.
  - 불러오는 중
  - 빈 목록
  - 입력 오류
  - 서버 오류
  - 권한 없음
- `요소`와 `상태`는 각각 7개 이하로 쓴다. 더 많으면 화면을 나누고 식별자를 따로 붙인다.
- `관련 문서`는 `<종류>: <문서나 절 이름>` 명사구로 쓴다.

## 다른 문서에서 화면 가리키기

| 위치 | 형식 | 예 |
| --- | --- | --- |
| 정책서와 기획서의 절 | 절 제목 바로 아래 줄에 식별자 목록 | 화면: `TRIP-02`, `TRIP-04` |
| 문서 본문 | 처음 가리킬 때 화면 이름 뒤 괄호에 식별자 | 여행 생성 화면(`TRIP-02`) |
| Issue, PR과 코멘트 | 식별자에 Figma 링크 | 화면: [`TRIP-02`](<Figma 링크>) |

- 같은 문서에서 같은 화면을 다시 가리키면 화면 이름만 쓴다.
- 화면 구성을 문장으로 옮겨 쓰지 않는다. 화면 구성이 필요하면 식별자로 Figma를 가리킨다.
- 화면 문구와 식별자의 표기는 [K15](../controlled-korean.md#k15-문장부호)를 따른다.
