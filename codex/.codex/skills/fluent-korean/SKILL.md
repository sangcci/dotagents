# Fluent Korean

한국어로 답변하거나 한국어 결과물을 만들 때, 의미가 분명하고 자연스러운 문장으로 작성합니다. 이 스킬은 [snflkd/fluent-korean](https://github.com/snflkd/fluent-korean)의 output-style을 Codex의 스킬 형식에 맞게 적용한 것입니다.

## 적용 범위

- 사용자가 외국어로 된 문장·용어·코드를 요구했다면 한국어로 바꾸지 않습니다. 고유명사와 기술 용어는 널리 쓰이는 한국어 표현이 있을 때만 사용하고, 그렇지 않으면 원어를 유지합니다.
- 코드, 코드 주석, 변수명, 로그 문자열, 커밋 메시지는 이 스킬로 다듬지 않습니다. 해당 프로젝트의 기존 관례를 우선합니다.
- 인용문은 원문을 유지합니다. 사용자가 특정 문체나 분량, 형식을 요구하면 그 요구를 우선합니다.
- 단순 맞춤법 교정, 번역, 또는 사용자의 고유한 말투 보존이 목표인 요청에는 해당 목적에 맞는 지침을 우선합니다.

## 작성 원칙

- 뜻을 이해하는 데 필요한 주어·목적어·수식어와 맥락을 생략하지 않습니다. 짧게 쓰더라도 무엇이, 왜, 어떻게 되는지 알 수 있어야 합니다.
- 헤더와 목록을 제외하면 명사구, 부사구, 연결어미로 문장을 끝내지 않고 서술어와 종결어미로 완결합니다.
- 조사와 어미를 과도하게 생략하지 않습니다. 문장 성분 사이의 관계가 선명하도록 자연스러운 통사 구조를 사용합니다.
- 의미가 더 명확해지는 경우에만 적절한 한자어를 사용합니다. 낯선 비유나 과장된 은유로 일반적인 표현을 대체하지 않습니다.
- 엠대시(—)로 관계를 압축하지 않습니다. 필요하면 콜론, 쉼표, 접속사 또는 별도 문장으로 풀어 씁니다.
- 사용자의 축약된 말투를 그대로 모방하기보다, 요청의 어조와 목적에 맞는 안정적인 문장으로 답합니다.

## 작업 방식

답변을 보내기 전에 한국어 문장이 조사·어미의 생략, 맥락 없는 명사 나열, 모호한 지시어, 불필요한 비유 때문에 뜻이 흐려지지 않는지 확인합니다. 코드 작업에서는 사용자에게 설명하는 한국어에만 이 원칙을 적용합니다.
