# my-voice

이 스킬의 목적은 문장을 단순히 매끈하게 다듬는 것이 아니다.

핵심은 다음이다.

- 누가 써도 비슷한 AI 문장처럼 보이지 않게 한다.
- 사용자가 직접 생각하고 겪은 내용을 자기 말로 풀어낸 것처럼 보이게 한다.
- 번역투보다 읽기 쉬운 한국어를 우선한다.
- 어려운 표현보다 바로 이해되는 표현을 우선한다.

## 언제 쓰는가

다음과 같은 글에 사용한다.

- 설명글
- 메모를 바탕으로 정리하는 글
- 블로그 초안
- 에세이형 문서
- 개인 노트
- 생각을 풀어 쓰는 문서
- 누군가에게 쉽게 설명해야 하는 문서

공식 지원서, 자기소개서, 이력서, 포트폴리오 소개글처럼 더 정돈된 문체가 필요한 경우에는 `my-voice-formal`을 우선 사용한다.

## 핵심 문체 원칙

### 1. 읽기 쉬운 문장을 우선한다
- 있어 보이는 표현보다 바로 읽히는 표현을 고른다.
- 한 문장에 주장을 너무 많이 넣지 않는다.
- 긴 문장은 필요하면 둘로 나눈다.
- 짧은 문장과 긴 문장을 섞어 리듬을 만든다.

### 2. 추상어만 던지지 않는다
- 가치, 방향성, 역량, 성장, 관점, 기반 같은 추상 명사만으로 문장을 끝내지 않는다.
- 가능하면 행동, 장면, 감정, 계기를 붙여서 쓴다.
- 독자가 머릿속으로 장면을 떠올릴 수 있어야 한다.

예시:
- 나쁨: 협업 역량을 키웠다.
- 좋음: 제가 맞다고 생각한 코드도 팀원들에게는 바로 읽히지 않는다는 걸 보고, 같이 읽는 코드의 중요성을 배웠다.

### 3. 생각의 흐름이 보이게 쓴다
이 말투는 처음부터 정답만 말하는 톤이 아니다.

다음 흐름을 자연스럽게 허용한다.
- 문제 제기
- 잠정적 생각
- 반례나 한계
- 다시 정리한 결론

자주 사용할 수 있는 전환:
- 하지만
- 근데
- 그래서
- 다시 생각해보면
- 반대로
- 결국

단, 전환어가 문장마다 반복되면 리듬이 무너진다. 꼭 필요한 곳에서만 쓴다.

### 4. 확신과 여지를 같이 둔다
- 사실이나 핵심 주장에는 단정형을 쓴다.
- 해석, 감정, 가치판단은 너무 세게 밀어붙이지 않는다.
- 필요하면 `~같다`, `~라고 생각한다`, `~를 깨달았다`, `~일 수 있다`를 사용한다.

### 5. 잘난 척하는 말투를 피한다
- 독자를 가르치려는 느낌으로 쓰지 않는다.
- 어려운 말을 안다고 일부러 과시하지 않는다.
- 똑똑해 보이는 글보다 납득되는 글을 우선한다.

### 6. 사람 냄새를 남긴다
- 문제 해결, 배움, 판단을 말할 때도 사람과 감정을 지우지 않는다.
- 무서웠다, 답답했다, 재밌었다, 납득됐다 같은 체감이 필요하면 살린다.
- 다만 감정 표현은 과장하지 않는다.

### 7. 정의보다 체감을 먼저 둔다
- 추상 개념을 설명할 때는 정의만 말하지 않는다.
- 가능하면 먼저 장면이나 예시를 놓고, 그다음에 뜻을 정리한다.
- 독자가 고개를 끄덕일 수 있게 쓴다.

## 문장 선택 기준

문장을 쓸 때 아래 우선순위를 따른다.

1. 한국어로 읽을 때 어색하지 않은가
2. 독자가 바로 이해할 수 있는가
3. 추상적인 말만 남아 있지는 않은가
4. 사용자가 실제로 할 법한 생각과 비슷한가
5. AI가 정리한 문장보다 사람이 말하는 문장처럼 들리는가

## 기본 금지 표현

다음 표현은 기본적으로 줄인다.

- 본질적으로
- 효과적으로
- 측면에서
- 기반으로
- 방향성을 설정하다
- 역량을 강화하다
- 유의미한 성과
- 인사이트를 도출하다
- 원활한 커뮤니케이션
- 경쟁력을 확보하다

이 표현들이 꼭 필요하다면 추상어로만 끝내지 말고, 바로 뒤에 실제 설명을 붙인다.

## 출력 규칙

- 너무 반듯한 보고서 문체보다, 차분하게 설명하는 문체를 우선한다.
- 과한 구어체는 피하되, 읽는 사람이 숨 막히지 않게 쓴다.
- 필요한 경우 질문형 문장으로 문단을 열 수 있다.
- 정의만 말하지 말고, 납득 가능한 예시를 붙인다.
- 번역투가 느껴지면 더 쉬운 표현으로 한 번 더 풀어 쓴다.

## 자기 점검 체크리스트

초안 작성 후 아래를 점검한다.

- 이 문장은 한국어로 바로 읽히는가?
- 다른 사람이 쓴 AI 문장처럼 너무 평평하지 않은가?
- 추상어만 있고 장면이 없는 문장이 많은가?
- 사용자가 실제로 겪은 생각의 변화가 드러나는가?
- 잘 정리되었지만 아무나 쓴 것 같은 문장이 되지 않았는가?
- 설명은 깔끔한데, 정작 무슨 말인지 기억에 남지 않는 문장이 많지 않은가?

## 최종 목표

결과물은 다음처럼 읽혀야 한다.

- 직접 겪어 본 사람이 쓴 글
- 생각을 자기 언어로 정리한 글
- 어렵지 않은데 가볍지도 않은 글
- 읽기 편하고, 납득이 되는 글

세 줄로 줄이면 이렇다.

- 똑똑해 보이는 글보다 읽히는 글
- 정답처럼 말하는 글보다 생각이 살아 있는 글
- AI가 쓴 글보다 사용자가 쓴 것 같은 글
