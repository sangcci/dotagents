# GLOSSARY.md 형식

`GLOSSARY.md`는 이 학습 워크스페이스의 표준 언어입니다. 모든 수업, 연습, 학습 기록이 여기의 용어를 따릅니다. 용어집을 만드는 일도 학습의 일부입니다. 개념을 정확한 정의로 압축할 수 있다는 것이 사용자가 이해했다는 증거이기 때문입니다.

## 구조

```md
# {주제} 용어집

{이 용어집이 다루는 주제에 대한 한두 문장의 설명.}

## 용어

**NAT (Network Address Translation)**:
사설 주소와 공인 주소를 바꾸어 주는, 라우터의 주소 변환 기능.
_쓰지 않을 말_: 주소 바꿔치기

**홀 펀칭**:
양쪽 기기가 서로에게 먼저 패킷을 보내 NAT에 통신 통로를 만드는 방법.
_쓰지 않을 말_: 구멍 뚫기
```

## 규칙

- **사용자가 이해한 용어만 추가합니다.** 용어집은 압축된 지식의 기록이지 사용자가 읽으며 배우는 사전이 아닙니다. 방금 소개한 개념이라면 사용자가 맞게 쓸 수 있을 때까지 기다렸다가 올립니다.
- **의견을 갖습니다.** 같은 개념에 단어가 여럿이면 가장 좋은 것 하나를 고르고 나머지는 _쓰지 않을 말_로 적습니다. 언어는 이렇게 압축됩니다.
- **정의를 짧게 씁니다.** 한두 문장입니다. 그것이 _무엇인지_ 정의하고, 무엇을 하는지나 어떻게 하는지는 쓰지 않습니다.
- **용어집 안의 용어로 정의합니다.** 용어가 용어집에 들어오면 다른 정의 안에서도 그 용어를 씁니다. 이렇게 하면 복잡한 용어를 나중에 이해하기 쉬워집니다.
- **자연스러운 묶음이 생기면 소제목으로 나눕니다.** 용어가 서로 어울리면 평평한 목록도 괜찮습니다.
- **모호함을 드러냅니다.** 해당 분야에서 용어를 느슨하게 쓰면 이 워크스페이스의 해석을 적습니다. 예: "이 워크스페이스에서 '연결'은 항상 TCP 연결을 뜻하며 UDP 흐름은 따로 부릅니다."
- **이해가 깊어지면 고칩니다.** 첫 주에 쓴 정의가 여섯째 주에는 틀릴 수 있습니다. 그 자리에서 고치고 낡은 항목을 남기지 않습니다.
