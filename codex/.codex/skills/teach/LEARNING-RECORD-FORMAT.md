# 학습 기록 형식

학습 기록은 `./learning-records/`에 두고 `0001-slug.md`, `0002-slug.md`처럼 번호를 순서대로 붙입니다. 디렉터리는 첫 기록을 쓸 때 만듭니다.

학습 기록은 가르침의 ADR입니다. 이후 세션의 방향을 정할 비자명한 교훈, 핵심 통찰, 사용자가 밝힌 사전 지식을 담습니다. 학습 근접 발달 영역을 가늠할 때 씁니다.

## 템플릿

```md
# {배운 것이나 확인된 것의 짧은 제목}

{1~3문장. 무엇을 배웠는지(또는 어떤 사전 지식이 확인됐는지), 그것이 이후 세션에 왜 중요한지.}
```

형식은 이것이 전부입니다. 기록은 한 문단이어도 됩니다. 칸을 채우는 것이 아니라 _이것이 이제 알려져 있다_는 사실과 _그래서 다음에 무엇을 가르칠지가 달라진다_는 이유를 남기는 것이 가치입니다.

## 선택 항목

진짜 가치를 더할 때만 넣습니다. 대부분의 기록에는 필요 없습니다.

- **Status** 프런트매터(`active | superseded by LR-NNNN`): 이전 이해가 틀린 것으로 드러나 대체될 때 씁니다.
- **근거**: 사용자가 어떻게 이해를 보였는지(맞힌 질문, 끝낸 연습, 언급한 경험). 주장을 다시 따져 볼 수 있을 때 유용합니다.
- **함의**: 이것이 이후 세션에서 무엇을 열고 무엇을 닫는지. 자명하지 않을 때 적습니다.

## 번호

`./learning-records/`에서 가장 큰 번호를 찾아 하나 올립니다.

## 기록을 쓰는 때

다음 중 하나에 해당하면 씁니다.

1. **사용자가 사소하지 않은 것을 진짜로 이해했음을 보였습니다.** 접해 본 정도가 아니라 개념을 맞게 쓸 수 있다는 증거가 있어야 합니다. 이후 가르칠 것의 하한선이 새로 정해집니다.
2. **사용자가 사전 지식을 밝혔습니다.** "X는 이미 알아요"를 기록해, 이후 세션에서 다시 가르치지 않게 합니다. 주장한 _깊이_도 함께 적습니다.
3. **오개념을 바로잡았습니다.** 틀리게 알던 것을 이유까지 이해했을 때입니다. 관련 주제에서 어디서 걸릴지를 예측해 주므로 가치가 큽니다.
4. **배움에 따라 미션이 바뀌었습니다.** 사용자가 자신이 생각한 것과 다른 것에 관심이 있음을 알게 된 경우입니다. [[MISSION.md]]를 연결하고 갱신합니다.

### 기록하지 않는 것

- 단지 다룬 내용. 다룬 것은 배운 것이 아닙니다. 증거를 기다립니다.
- 이미 [[GLOSSARY.md]]에 용어 정의로 간결하게 담긴 것. 중복하지 않습니다.
- 세션별 활동 일지. 학습 기록은 일기가 아니라 판단의 근거가 되는 통찰입니다.

## 대체

나중 기록이 앞선 기록과 모순되면(사용자의 이해가 깊어지거나 바로잡힘) 앞선 기록을 지우지 않고 `Status: superseded by LR-NNNN`으로 표시합니다. 이해가 어떻게 달라졌는지의 이력 자체가 유용한 신호입니다.
