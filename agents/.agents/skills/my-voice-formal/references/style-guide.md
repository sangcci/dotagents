# my-voice-formal style guide

## 한 줄 요약

이 말투의 핵심은 **공식 문서답게 정돈되어 있으면서도, 실제 사람이 직접 정리한 것처럼 읽히는 문장**이다.

## 이 말투가 좋아하는 것

- 정리된 문장
- 실제 경험이 보이는 문장
- 판단 기준이 드러나는 문장
- 추상어 뒤에 행동이 붙는 문장
- 과장보다 신뢰를 주는 문장
- 생각이 바뀐 계기가 보이는 문장

## 이 말투가 싫어하는 것

- AI 자기소개서처럼 전부 비슷한 문장
- 역량, 성장, 협업만 반복되는 추상적 서술
- 화려하지만 비어 있는 미사여구
- 실제 장면 없이 결과만 나열하는 문장
- 모든 문장이 같은 호흡으로 이어지는 글

## 좋은 전개 방식

### 1. 처음 생각 → 계기 → 변화
예시:
- 처음에는 혼자 빨리 구현하는 게 중요하다고 생각했습니다.
- 하지만 팀 프로젝트를 하면서 설명과 조율이 더 중요하다는 걸 배웠습니다.
- 이후에는 제가 이해한 내용을 먼저 말로 풀어보는 습관을 들였습니다.

### 2. 행동 → 배운 점
예시:
- 회의 전에 안건을 미리 읽고 제 의견을 적어 갔습니다.
- 이 경험을 통해 준비가 소통의 질을 바꾼다는 걸 느꼈습니다.

### 3. 문제 → 해결 시도 → 지금의 기준
예시:
- 처음에는 코드 스타일이 다르면 불편하다고만 생각했습니다.
- 하지만 왜 다르게 읽히는지 설명해보니 문제가 더 선명해졌습니다.
- 지금은 정답을 찾기보다 기준을 먼저 맞추는 편입니다.

## 자주 쓰면 좋은 표현

- 처음에는 ~라고 생각했습니다
- 하지만 ~를 겪고 생각이 바뀌었습니다
- 이 경험 이후로는 ~하려고 했습니다
- 저는 이 과정에서 ~를 배웠습니다
- 혼자서는 보지 못했던 부분을 알게 됐습니다
- 지금은 ~를 더 중요하게 생각합니다

## 줄이면 좋은 표현

- 본질적으로
- 기반으로
- 측면에서
- 방향성
- 프로세스
- 인사이트
- 차별화된 경쟁력
- 유의미한 성과 창출
- 원활한 커뮤니케이션 역량

## 표현 변환 예시

### 예시 1
- 나쁨: 협업 역량을 기반으로 프로젝트를 성공적으로 수행했습니다.
- 좋음: 혼자 맞다고 생각한 코드도 팀원들에게는 바로 읽히지 않는다는 걸 겪은 뒤, 설명과 조율이 협업의 핵심이라고 생각하게 됐습니다.

### 예시 2
- 나쁨: 해당 경험은 저의 성장 방향성을 구체화하는 계기가 되었습니다.
- 좋음: 그 경험 이후로는 무엇을 잘하고 싶은지보다, 어떤 기준으로 일하고 싶은지가 더 선명해졌습니다.

### 예시 3
- 나쁨: 저는 책임감을 바탕으로 주도적으로 업무를 수행했습니다.
- 좋음: 맡은 일을 끝내는 데서 멈추지 않고, 팀 전체가 막히는 지점이 있으면 같이 보는 쪽을 더 중요하게 생각했습니다.

## 빠른 자가 점검

1. 이 문장은 너무 뻔한 자소서 문장처럼 들리지 않는가?
2. 추상어 뒤에 실제 장면이나 행동이 붙어 있는가?
3. 결과만 있고 생각 변화는 빠져 있지 않은가?
4. 과장 없이도 신뢰가 생기는가?
5. 읽는 사람이 이 사람의 판단 기준을 느낄 수 있는가?
