# my-voice-formal

이 스킬은 자기소개서, 이력서, 지원서, 포트폴리오 소개글처럼 공식적인 문서를 쓸 때 사용한다.

목표는 두 가지를 동시에 만족하는 것이다.

- 공식 문서답게 정돈되어 있어야 한다.
- 그런데도 AI가 쓴 것처럼 다 비슷한 말투가 되면 안 된다.

즉, 이 스킬은 **반듯하지만 살아 있는 문장**을 만드는 데 목적이 있다.

## 언제 쓰는가

다음과 같은 문서에 사용한다.

- 자기소개서
- 지원서 문항 답변
- 이력서 소개글
- 포트폴리오 자기소개
- 회고형 지원 문서
- 대외활동 지원 글
- 면접 대비용 서면 답변

일반 설명문, 메모, 블로그 초안처럼 더 자유로운 문서는 `my-voice`를 우선 사용한다.

## 핵심 원칙

### 1. 공식 문서라도 사람 냄새를 지우지 않는다
- 지나치게 매끈한 문장만 이어지면 AI처럼 보인다.
- 실제 계기, 실제 판단, 실제 행동이 보여야 한다.
- 감정은 절제하되 완전히 삭제하지 않는다.

예시:
- 나쁨: 협업 역량을 기반으로 프로젝트 성과를 도출했습니다.
- 좋음: 혼자서는 맞다고 생각했던 코드가 팀원들에게는 바로 읽히지 않는다는 걸 경험한 뒤, 협업에서는 설명과 조율이 더 중요하다고 생각하게 됐습니다.

### 2. 추상어는 행동으로 받쳐준다
다음 단어는 사용할 수는 있지만 단독으로 두지 않는다.

- 성장
- 역량
- 협업
- 소통
- 책임감
- 문제 해결
- 주도성
- 가치

이 단어를 썼다면 바로 뒤에 아래 중 하나를 붙인다.
- 어떤 장면이 있었는지
- 무엇을 했는지
- 생각이 어떻게 바뀌었는지
- 결과적으로 무엇을 배웠는지

### 3. 미사여구를 줄인다
다음 표현은 기본적으로 피한다.

- 끊임없는 도전정신
- 차별화된 경쟁력
- 탁월한 문제 해결 능력
- 효과적인 커뮤니케이션 능력
- 주도적인 자세
- 유의미한 성과를 창출했다

이런 표현 대신 실제 경험을 쓴다.

### 4. 결론보다 변화 과정을 보여준다
이 말투의 강점은 `무엇을 잘했다`보다 `어떻게 생각이 바뀌었는지`에 있다.

가능하면 아래 흐름을 쓴다.
- 처음에는 어떻게 생각했는지
- 어떤 장면에서 막혔는지
- 무엇을 바꿨는지
- 지금은 어떻게 생각하는지

### 5. 과한 구어체는 줄이되, 너무 딱딱하게 만들지 않는다
- `진짜`, `너무`, `그냥`, `오지게` 같은 표현은 공식 문서에서는 줄인다.
- 대신 문장 전체 리듬은 부드럽게 유지한다.
- `~했습니다`, `~깨달았습니다`, `~생각했습니다`, `~하려고 했습니다` 같은 표현을 자연스럽게 사용한다.

### 6. 문장 길이를 균일하게 만들지 않는다
- 모든 문장이 같은 길이, 같은 구조면 AI처럼 보인다.
- 핵심 문장은 짧게 자른다.
- 설명은 필요한 만큼만 길게 쓴다.
- 문단 끝은 가능하면 한 번 더 정리한다.

### 7. 성과보다 판단 기준을 보이게 한다
- 무엇을 해냈는지만 쓰지 않는다.
- 왜 그런 선택을 했는지, 무엇을 중요하게 여겼는지를 드러낸다.
- 읽는 사람이 `이 사람은 이런 기준으로 움직이는구나`를 느낄 수 있어야 한다.

## 공식 문서용 문체 가이드

### 선호 표현
- 처음에는 ~라고 생각했습니다
- 하지만 ~를 겪고 생각이 바뀌었습니다
- 이 경험 이후로는 ~하려고 했습니다
- 저는 이 과정에서 ~를 분명히 배웠습니다
- 혼자서는 보지 못한 부분을 ~를 통해 알게 됐습니다
- 지금은 ~를 더 중요하게 생각합니다

### 줄일 표현
- 본질적으로
- 측면에서
- 기반으로
- 방향성
- 프로세스
- 인사이트
- 역량 강화
- 성과 창출
- 효율성 제고

## 출력 규칙

- 과장보다 신뢰를 우선한다.
- 멋있어 보이는 문장보다 납득되는 문장을 우선한다.
- 추상어만 남으면 반드시 장면이나 행동으로 다시 풀어 쓴다.
- 읽는 사람이 `무슨 말을 하는지 알겠다`에서 끝나지 않고 `왜 이런 생각을 하는지도 알겠다`까지 느끼게 쓴다.

## 문장 점검 규칙

초안이 나오면 아래를 확인한다.

1. 이 문장이 너무 AI 자기소개서처럼 들리지는 않는가?
2. 추상어가 실제 경험 없이 떠 있지는 않은가?
3. 사용자의 실제 판단과 생각 변화가 보이는가?
4. 문장이 지나치게 번듯해서 개성이 사라지지는 않았는가?
5. 읽는 사람이 `아, 이 사람은 이런 식으로 생각하는구나`를 느낄 수 있는가?
6. 문장 하나하나는 깔끔한데, 전부 어디서 본 말처럼 느껴지지는 않는가?

## 최종 목표

결과물은 아래처럼 읽혀야 한다.

- 성실하게 정리된 문장
- 그런데도 실제 사람이 쓴 것 같은 문장
- 과장되지 않았지만 믿음이 가는 문장
- 읽기 편하고, 생각의 흐름이 보이는 문장

세 줄로 줄이면 이렇다.

- 뻔한 자소서 문장보다 살아 있는 문장
- 추상적인 칭찬보다 실제 판단이 보이는 문장
- AI가 대신 써준 글보다 사용자가 직접 정리한 것 같은 글
